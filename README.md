# pc-games

Автономный парсер раздач компьютерных игр для Windows с трекера RuTracker. Автоматически собирает базу данных в формате JSON (названия, размеры, magnet-ссылки, подразделы, обложки, скриншоты, описания), ежедневно отслеживает новые и обновлённые раздачи через Atom-ленты и выгружает изменения на GitHub.

Создан на основе проверенной архитектуры `switch-games` и `console-games`.

---

## Ключевые возможности и фильтры

1. **Строгая фильтрация `[portable]`**:
   - В базу включаются **только портативные версии** игр (не требующие установки через `setup.exe`).
   - Обычные инсталляторы, ISO-образы и репаки без пометки portable автоматически отсекаются.

2. **Ограничение по размеру ($\le 60\text{ ГБ}$)**:
   - Парсер строго контролирует размер каждой раздачи ($64\,424\,509\,440$ байт). Раздачи больше 60 ГБ в базу не попадают.

3. **Точная привязка к подразделам**:
   - Каждая игра содержит `subforum_id`, `subforum` и `subforum_slug`.
   - Генерируется структурированный каталог `data/subforums.json` со счётчиками игр для построения аналогичного каталога в вашем клиентском приложении.

4. **Исключение нецелевых веток (Чёрный список)**:
   - Полностью исключены подразделы:
     - `f=1151` — Поиск и обсуждение игр для Windows
     - `f=2228` — Для некондиционных раздач
     - `f=68` — Архив (Игры)
     - `f=1175`, `f=1176`, `f=2341` — Флудилки и обсуждения
     - `f=139` — Патчи и русификаторы

## Архитектура проекта

```
pc-games/
├── data/
│   ├── pc_games.json          # Основная база игр [portable] <= 60 ГБ
│   ├── subforums.json         # Каталог подразделов для клиентского UI
│   └── pc_games_stats.json    # Статистика раздач (сиды, пиры, скачивания)
├── core/
│   ├── network.py             # Сетевой слой (curl_cffi, proxy, CF-bypass, Chrome)
│   ├── cf_utils.py            # Помощники решения Turnstile и инжекции cookies
│   ├── filter.py              # Валидация [portable] и лимита <= 60 ГБ
│   ├── atom.py                # Парсер Atom-лент (мгновенный сбор без CF)
│   ├── forum.py               # Постраничный обход viewforum.php
│   ├── topic_parser.py        # Парсинг страницы темы (обложки, скриншоты, описание)
│   ├── stats.py               # Сбор статистики трекера
│   └── storage.py             # Атомарная запись JSON и лог changes.txt
├── config/
│   └── subforums.py           # Реестр подразделов, slug, исключения (f=1151, 2228, 68)
├── scripts/
│   └── test_connection.py     # Диагностика подключения и кук
├── tests/
│   ├── test_filter.py         # Юнит-тесты фильтрации [portable] и размера
│   └── test_subforums.py      # Тесты исключений и метаданных подразделов
├── scraper.py                 # Главный CLI-парсер
├── login_rutracker.py         # Авторизация на RuTracker (curl / Chrome)
├── setup_vps.sh               # Интерактивный установщик для VPS
├── run.sh                     # Скрипт для cron (pull -> scrape -> commit -> push)
├── requirements.txt           # Зависимости Python
├── .env.example               # Шаблон настроек окружения
└── changes.txt                # Лог последних изменений
```

## Быстрый запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск парсера
```bash
# Стандартный цикл (проверка Atom-лент всех подразделов + дообогащение + статистика):
python scraper.py

# Только один конкретный подраздел (например f=52 Ролевые игры):
python scraper.py --subforum 52

# Полный постраничный обход всех страниц всех подразделов:
python scraper.py --full

# Пропустить сбор статистики раздач:
python scraper.py --skip-stats

# Только сбор статистики торрентов (сиды, пиры, скачивания):
python scraper.py --stats-only
```

### 3. Диагностика сети
```bash
python scripts/test_connection.py
```

### 4. Запуск юнит-тестов
```bash
python -m unittest discover tests
```
